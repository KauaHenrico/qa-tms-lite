# Resposta à área de operações

**Para:** Camila Ferraz — Coordenação de Operações
**Assunto:** Confiabilidade do TMS Lite

Camila,

Hoje não é seguro confiar no TMS Lite como única fonte para confirmar o andamento de uma entrega. O ponto mais grave é que uma carga pode aparecer como entregue sem passar pelas etapas de coleta, trânsito e saída para entrega. O sistema também aceita cancelamento depois do início do trânsito e permite alterar uma entrega já concluída.

Na prática, isso pode levar o atendimento a informar uma entrega como concluída quando ela ainda não chegou ao cliente. O histórico também deixa de ser uma fonte confiável para investigar o que aconteceu.

Enquanto a correção não for aplicada, a recomendação é não confirmar entrega, devolução ou cancelamento somente pelo TMS. Antes de comunicar o cliente, validem o status com a transportadora ou com o centro de distribuição. Também é necessário conferir manualmente o prazo informado, pois há entregas com data incorreta.

Foram encontrados outros problemas no cadastro, no código de rastreio, na busca e no contador da lista. Eles aumentam o retrabalho, mas o controle de status é a prioridade porque pode gerar uma informação errada diretamente para o cliente.

Depois das correções, é necessário repetir os cenários de status, prazo e cadastro antes de liberar o sistema como referência operacional.
